# Profile Playground

Небольшое React + Material UI приложение с карточкой профиля и панелью настроек.

## Функции

- изменение имени и фамилии
- выбор роли
- изменение размера аватара
- смена цвета кнопок
- смена размера кнопок
- переключение онлайн-статуса
- выбор вида карточки
- показ и скрытие Alert

## Технологии

- React
- Vite
- Material UI
- CSS
